# 📱 Projeto Redes Sociais - Mockup Interativo

Um projeto front-end interativo desenvolvido com **HTML5** e **CSS3** focado em técnicas avançadas de posicionamento e design de componentes. O objetivo principal é simular uma interface de smartphone totalmente funcional no centro da tela, onde o usuário interage com botões de redes sociais e o conteúdo do dispositivo se adapta dinamicamente.

---

## 🛠️ Desafios Técnicos Superados neste Projeto:

* **Posicionamento Avançado (Iframe e Camadas):** Uso estratégico de propriedades CSS para alinhar perfeitamente uma janela de navegação interna (`iframe`) dentro de uma moldura de celular fixa.
* **Scroll Interno Organizado:** Configuração de comportamento de rolagem isolado para simular o uso real de um aplicativo de celular.
* **Efeitos de Hover Dinâmicos:** Criação de transições suaves (`transition`) e efeitos visuais nos botões arredondados das redes sociais ao passar o mouse.
* **Design Responsivo:** Centralização e adaptação do mockup para que a experiência faça sentido em resoluções variadas.
